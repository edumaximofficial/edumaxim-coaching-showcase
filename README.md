# EduMaxim for Coaching Institutes

**See it: https://edumaximofficial.github.io/edumaxim-coaching-showcase/**

EduMaxim marks OMR tests with a phone camera and shows every student's growth, test after test. It is built for NEET, JEE and foundation coaching.

## How it works

1. **Answer key in one line.** Type `BADCC ABDCA…` or tap bubbles. Up to 200 questions, with NEET/JEE negative marking and sections such as `1-45 Physics`.
2. **Print OMR sheets.** Print a blank sheet to photocopy, or one per student with the name and roll number already filled. A numbered question paper prints too.
3. **Photograph each sheet.** The roll number finds the student and every bubble is read. Doubtful marks are highlighted. Then *Save & scan next*. An OMR machine's Excel export works too.
4. **Ranks and growth.** You get a live rank list and an Excel rank list. If the key was wrong, fix it once and everything is re-marked. Parents see the score, the rank in the batch, section-wise bars and a growth graph.

It also covers batches, course fees in instalments, attendance with parent alerts, online chapter quizzes, practice for weak topics, and SMS/WhatsApp to parents.
